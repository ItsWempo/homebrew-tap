# ItsWempo Tap

## How do I install these formulae?

`brew install itswempo/tap/<formula>`

Or `brew tap itswempo/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "itswempo/tap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
